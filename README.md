# NIKKE 4주년 개인 분석서

「승리의 여신: 니케」 4주년 업데이트를 직접 플레이한 경험과 공개 자료를 바탕으로 정리한 정적 웹사이트입니다. 스토리·캐릭터·상품과 라이브 서비스 운영, 이용 및 매출 지표를 함께 다룹니다.

**게시 주소:** https://qorrkdwns.github.io/nikke-4th-analysis/

## 파일 구성

```text
.
├── index.html                 # 웹사이트 본문, CSS, JavaScript
├── assets/                    # 이미지 및 웹폰트
├── data/                      # 검색 관심도·분기 실적 원자료(CSV)와 설명
├── .nojekyll                  # GitHub Pages 설정
├── Pretendard-LICENSE.txt     # 폰트 라이선스
└── README.md
```

## 실행 및 업데이트

- 별도 빌드 과정이 없는 정적 HTML 사이트입니다. 로컬에서는 `index.html`을 브라우저로 열어 확인할 수 있습니다.
- 공개 사이트는 GitHub Pages에서 제공됩니다. `main` 브랜치에 변경 사항을 반영하면 배포됩니다.
- 이미지와 폰트는 `./assets/` 상대경로를 사용하므로, `index.html`과 `assets/`의 위치 관계를 유지합니다.
- 로컬 파일로 열었을 때 일부 영상은 외부 링크로 표시될 수 있습니다. 실제 게시 상태는 위 Pages 주소에서 확인합니다.

## 화면 이동

상단 메뉴로 6개 주요 섹션을 선택하고, 하단 항목·이전/다음 버튼·방향키·스크롤로 하위 화면을 이동합니다. 주년 연혁에서는 픽업 정보를 확인할 수 있으며, 영상과 출처는 해당 화면에서 연결됩니다.

## 데이터 및 출처

`data/` 폴더에는 다음 자료를 보관합니다.

- `google-anniversary-20261020-20261108.csv` — 4주년 관련 검색 관심도
- `google-anniversary-alias-check.csv` — 검색어 표기 비교
- `shiftup-nikke-quarterly-2026q2.csv` — 시프트업 니케 분기별 영업수익
- `data/README.md` — 데이터 설명 및 출처

**자료 확인 기준일:** 2026년 11월 8일. 지표별 집계 기간과 개별 출처는 웹사이트에서 확인합니다. 데이터를 수정할 때는 본문의 그래프와 설명에 반영된 수치도 함께 확인합니다.

## 참고

비공식 개인 분석서이며 게임사 또는 퍼블리셔의 공식 웹사이트가 아닙니다. 게임 이미지·캐릭터·영상 등의 권리는 각 권리자에게 있습니다. Pretendard 폰트의 라이선스는 `Pretendard-LICENSE.txt`를 참고합니다.
