# 승리의 여신: 니케 4주년 분석서

정적 HTML 웹사이트입니다. 별도 설치나 빌드 없이 게시할 수 있습니다.

- `index.html`, `assets/`, `.nojekyll`을 같은 위치에 유지합니다.
- GitHub Pages에서 사용할 저장소의 루트 또는 지정한 docs 폴더에 내용을 넣습니다.
- 저장소 Settings → Pages에서 해당 브랜치와 폴더를 선택합니다.
- `#history`, `#schedule` 등 페이지 주소를 직접 공유할 수 있습니다.
- 상단 메뉴와 같은 6개 본문 섹션으로 구성됩니다. 같은 목차의 하위 내용은 하단 항목, 좌우 버튼, 가로 스와이프 또는 좌우 방향키로 넘깁니다. 아래로 스크롤하면 같은 목차의 다음 하위 내용을 먼저 가로로 넘기고, 마지막 하위 내용 뒤에는 다음 목차로 이동합니다. 위로 스크롤하면 역순으로 이동합니다. 각 화면은 내용과 출처를 함께 표시하며 데스크톱에서는 내부 세로 스크롤 없이 다음 화면으로 넘깁니다. 모바일에서는 현재 화면의 본문을 세로로 끝까지 읽은 뒤 다음 내용으로 이동합니다.
- 감상 댓글은 화면에 들어가는 여러 개를 함께 보여 주고, 공간이 부족할 때만 이전 댓글·다음 댓글 버튼으로 다음 묶음을 읽습니다. 댓글 영역 위의 휠 입력으로 화면이 넘어가지 않습니다.
- 주년 연혁에 마우스를 올리면 당시 픽업 배너를 볼 수 있습니다.
- HTML 파일을 직접 열면 모션 영상은 YouTube 링크로 표시됩니다. GitHub Pages 등 웹 주소에서는 내장 플레이어를 사용하며, 재생 오류 시 공식 영상 링크로 전환합니다.
- Pretendard 폰트를 함께 제공합니다. 라이선스는 `Pretendard-LICENSE.txt`에 포함했습니다.

사업 지표 관측일: 2026년 10월 29일 ~ 11월 7일. 자료 확인일: 2026년 11월 8일. 개별 지표의 실제 집계 기간은 본문에 명시했습니다. 출처는 각 페이지 및 공식 이벤트·모집 링크에서 확인할 수 있습니다.
