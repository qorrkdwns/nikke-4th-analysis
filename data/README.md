# 검색 관심도 원자료

- 2026년 11월 8일 Google Trends 공식 탐색 화면의 CSV 다운로드 기능으로 확보했습니다.
- 대한민국 / 웹 검색 / 모든 카테고리 / 2026.10.20 ~ 11.08.
- google-anniversary-20261020-20261108.csv: 본문에 사용한 5개 검색어 동시 비교 원자료입니다.
- 그래프에는 MARIA-n을 제외한 4개 검색어, 11월 7일까지의 일별 값을 사용합니다. MARIA-n의 상대지수는0~1입니다. 11월8일은 당일 집계 중이므로 원자료에만 보존합니다.
- google-anniversary-alias-check.csv: MARIA-n 대신 ‘니케 마리아’를 조회한 보조 비교입니다. 첫 조회와 표본 차이가 있어 본문 그래프에 섞지 않았습니다.
- 지수는 공통 비교에서의 상대 검색 관심도이며 절대 검색량이 아닙니다. 검색어가 겹치므로 합산하지 않습니다.
